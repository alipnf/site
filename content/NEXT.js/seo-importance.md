# Mengapa SEO sangat penting?

SEO penting untuk sebuah brand karena ketika SEO pada sebuah website bagus,
maka saat website tersebut dicari di internet, posisinya akan berada lebih
tinggi di hasil pencarian.

Ada 3 pilar utama untuk mengoptimalkan SEO:
- Mengoptimalkan performa website agar mudah dirayapi oleh mesin pencari
- Membuat konten berdasarkan kata kunci tertentu
- Meningkatkan reputasi website agar mesin pencari tahu bahwa website tersebut
  merupakan sumber yang tepercaya

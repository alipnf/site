# Search Systems (Cara Kerja Mesin Pencari)

Search system biasanya disebut sebagai search engine seperti Google, Bing,
DuckDuckGo, dan lain-lain.

Search system memiliki beberapa tanggung jawab utama, yaitu:
- Menjelajahi web dan membaca (parsing) konten di dalam website (crawling)
- Menyimpan data yang dikumpulkan selama proses crawling agar dapat diakses (indexing)
- Menjalankan resource pada halaman seperti JavaScript yang dapat meningkatkan
  fitur dan memperkaya konten website (rendering)
- Menyusun halaman hasil pencarian yang relevan berdasarkan input pengguna
  dengan menerapkan berbagai kriteria peringkat (ranking)
